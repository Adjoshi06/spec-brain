# Seed data

Everything under `personal/` and `office/` is **fictional demo data written for this
hackathon**, in the voice of an architect (the persona is my father's practice). Projects,
clients, contacts and the "rep" are invented. Product names are real; the product facts the
agent uses come from live manufacturer pages scraped with Bright Data, not from these notes.

- `personal/` → Cognee dataset `personal` (node sets: note, lesson, contact, decision)
- `office/`   → Cognee dataset `office`   (node set: standard)
- `public/sources.json` → URLs scraped into Cognee dataset `public` (node set: datasheet)
